Inspector limits: 1 MiB, 32 JSON levels, 50,000 nodes, 256 sections/references, 64 heading-path parts and 256 metadata entries per object. Section line/level integers must fit u32 for native/WASM portability. These are inspector admission limits, not changes to mdport.v1 or allocation guarantees. Startup/compute deadlines are 12/10 seconds. No large-corpus performance or consumer adoption claim.
